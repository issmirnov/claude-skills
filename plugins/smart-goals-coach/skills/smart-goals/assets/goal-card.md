# Goal card template

Fill this in at the end of the session. One block per goal. Keep each line short and in the person's own words.

```
GOAL: [one-sentence SMART goal]

Specific:    [what they'll do or have]
Measurable:  [baseline] -> [target], tracked by [how]
Achievable:  [weekly commitment] | confidence [N]/10
Relevant:    [their reason, in their words]
Time-bound:  done by [date] | check-ins [dates]

First step (next 48h):  [action]
If-then plan:           If [obstacle], then I will [response].
```

If they parked other goals, add:

```
LATER: [goal], [goal]
```
